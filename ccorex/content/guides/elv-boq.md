An ELV BOQ lists every extra-low-voltage system in the scope (CCTV, access control, intercom, public address, structured cabling, MATV and similar) broken down into head-end equipment, field devices, cabling, containment, software and commissioning, with a quantity and rate for each item. The key to a good ELV BOQ is structure: by system, then by building and floor, so that device counts, cable lengths and licences can be checked against the drawings and each other. This guide covers how to set it up, take off quantities and price it.

## What ELV covers

ELV packages differ between residential, commercial and industrial projects. A typical scope includes some combination of:

- **CCTV / video surveillance**: cameras, recorders or servers, video management software, monitors, storage
- **Access control**: card readers, door controllers, electromagnetic locks, exit buttons, break-glass units, door contacts
- **Intercom and video door phones**: entrance panels, indoor units, guard stations
- **Public address and background music**: amplifiers, speakers, paging consoles, zone controllers
- **Structured cabling**: data outlets, patch panels, racks, copper and fibre backbone
- **MATV / SMATV**: antennas, amplifiers, splitters, TV outlets
- **Car park systems**: barrier gates, vehicle recognition, car park guidance
- **Security alarms**: intrusion detection, panic buttons
- **Other**: nurse call, guard tour, building management interfaces, as specified

ELV systems often interface with fire alarm, lifts, ACMV and the building management system. Those interfaces need to be priced by someone; make sure it is clear who.

## Singapore context

In Singapore, structured cabling and telecommunication facilities in buildings are subject to IMDA requirements, and ELV systems that interface with fire alarm (for example, access control doors releasing on fire alarm) need to align with SCDF fire safety requirements and the fire alarm design under SS CP 10. Your specification will usually reference the standards and editions that apply. Price to the specification and note anything that appears to conflict with it.

## How to prepare an ELV BOQ

### 1. Read the specification by system

ELV specifications are often split into a section per system. For each, note approved brands, resolution or performance requirements, licence requirements, storage or retention requirements, warranty and maintenance obligations.

### 2. Confirm scope boundaries

Write down who provides:

1. Containment (conduits, trunking, cable trays)
2. Power supply to racks, cameras and door locks
3. Network switches and internet connection
4. Doors, door hardware and frames for access control
5. Integration with fire alarm, lifts and ACMV

These five items cause more ELV pricing disputes than any device count.

### 3. Set up the structure

Use a section per system. Within each section, group items:

- **Head-end**: servers, recorders, controllers, amplifiers, racks
- **Field devices**: cameras, readers, speakers, outlets, intercom units
- **Cabling**: by cable type, in linear metres
- **Containment**: if in scope
- **Software and licences**
- **Testing, commissioning, programming and training**

Within field devices and cabling, break down by building and floor.

### 4. Take off field devices

Count devices by type from the layout drawings, area by area. For access control, take off per door: each controlled door may need a reader, lock, exit button, break-glass unit and door contact, so a per-door assembly avoids missed parts. For CCTV, count cameras by type (dome, bullet, PTZ, indoor, outdoor) because their prices differ.

### 5. Measure cabling

Measure cable runs by type from each device to the rack, panel or controller, including vertical risers and drops. If the BOQ allows a per-point rate, make sure your rate reflects the actual average run lengths on this project, not a typical one from another job.

### 6. Price head-end equipment

Size recorders, storage, switches and amplifiers to the device counts and specification. Price from current supplier quotes, and check that licences and accessories are included.

### 7. Add licences, programming and commissioning

List software licences per camera, door or device as separate items. Add programming, configuration, testing, commissioning, training and documentation.

### 8. Apply markups and summarise

Apply material and installation markups, preliminaries, and show GST separately at the prevailing rate.

## Example ELV BOQ structure

| Section | Item group | Typical unit |
|---|---|---|
| CCTV | Cameras by type | nr |
| CCTV | Recorders / servers, storage | set |
| CCTV | VMS licences | nr |
| Access control | Per-door assembly | nr (door) |
| Access control | Controllers, software | nr / lot |
| Intercom | Entrance panels, indoor units | nr |
| PA / BGM | Speakers, amplifiers | nr |
| Structured cabling | Data outlets, patch panels, racks | nr |
| All systems | Cabling by type | m |
| All systems | Testing, commissioning, training | item |

Using assemblies (a standard set of components priced together) is especially useful in ELV, where a single "door" or "camera point" contains several parts.

## ELV BOQ checklist

- [ ] Every system in the specification has a BOQ section
- [ ] Scope boundaries for containment, power, network and doors confirmed
- [ ] Devices counted by type, per building and floor
- [ ] Access control priced per door with all components
- [ ] Cabling measured by type, including risers and drops
- [ ] Head-end equipment sized to device counts
- [ ] Storage sized to the specified retention requirement
- [ ] Licences listed per device where required
- [ ] Interfaces with fire alarm, lifts and ACMV priced or excluded
- [ ] Programming, testing, commissioning and training included
- [ ] Warranty and maintenance obligations reflected
- [ ] Exclusions and assumptions listed

## Questions to raise during the tender

ELV specifications are often written as performance requirements, which leaves room for interpretation. Raise a tender query or state your assumption on:

- Camera resolution, recording frame rate and storage retention period, if not stated
- Whether door hardware and electromagnetic lock brackets are supplied by the door contractor or by you
- Who provides the network switches, firewall and internet connection
- Whether the client's IT team will configure the network or expects you to
- Number of years of software support and licence renewal included
- Whether existing systems must be integrated, and what information is available about them

Written answers protect your price if the scope is interpreted differently later.

## Common mistakes

1. **Counting devices but not the parts behind them.** A camera point needs a camera, a mount, a cable, a switch port and a licence. A door needs more than a reader.
2. **Assuming containment and power are by others.** If the tender is silent, ask or qualify. Otherwise you may be installing them for free.
3. **Using a generic per-point cable rate.** Run lengths vary between projects. A low-rise spread-out site and a compact tower are not the same.
4. **Leaving out licences.** Software licences and annual support can be a meaningful part of the ELV price.
5. **Undersizing head-end equipment.** Storage, switch ports and power budgets must match the final device count.
6. **Forgetting integration and programming.** Cause-and-effect with fire alarm, lift integration and system programming take engineering time.
7. **Not updating after revisions.** Device layouts change often in ELV. Re-check counts against the latest drawings before submission.
