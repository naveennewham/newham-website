# CCorex Site (Standalone)

A standalone Nuxt 3 site for CCorex, intended for deployment at ccorex.com.

## Quick start

1. Install dependencies

```
npm install
```

2. Run the dev server

```
npm run dev
```

## Structure

- TailwindCSS with dark cyan/teal theme
- Pages: Overview (/), Apps (/apps), Pricing (/pricing), Integrations (/integrations), FAQ (/faq)

## Deploy

- Build: `npm run build`
- Start: `npm run start`
- Or deploy to Vercel/Netlify directly from this subfolder.
